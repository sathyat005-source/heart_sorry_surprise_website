# Free Sorry Surprise Website ❤️

## 1. Add your name and their name
Open `script.js` and edit the SETTINGS section:

personName: "Their Name",
senderName: "Your Name",

You can also replace the final apology message there.

## 2. Add photos
Put your images inside the `images` folder and rename them:

photo1.jpg
photo2.jpg
photo3.jpg
photo4.jpg

JPG, PNG or WEBP files are fine, but if you use another extension, update the filename in `index.html`.

## 3. Add music
Put an MP3 file inside the `music` folder and rename it:

song.mp3

The music starts after the visitor taps the first button because browsers normally block automatic audio.

## 4. Change the apology text
The easiest place is directly in `index.html`. Search for:
- "I am really sorry."
- "If I could go back..."
- "Thank you for being you."

Replace those paragraphs with your own words.

## 5. Run it
Open `index.html` in a browser.

## 6. Make it a free shareable link
Create a GitHub repository, upload all files/folders, then enable GitHub Pages:
Repository -> Settings -> Pages -> Deploy from branch -> main -> /(root) -> Save.

Your link will look like:
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

Do not upload private or sensitive photos if you are using a public repository.
